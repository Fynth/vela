# Browser regression tests

Fresh headless Chromium instances exercise the real Rust server, isolated SQLite/storage and built Dioxus WASM. No signed-in browser profile is used. `server.sh` owns and removes its own mktemp directory, never the development library.

```bash
cargo build --locked -p vela-server
scripts/build-web.sh
npm ci --prefix tests/browser
(cd tests/browser && npx playwright install chromium && npx playwright test)
```

Use `VELA_LIVE_IMPORT_TEST=1` to include the external direct-download import test; ordinary tests are deterministic and offline after dependency installation. The live test uses **Example.ogg by JesseW**, licensed [CC BY-SA3.0](https://creativecommons.org/licenses/by-sa/3.0/) and documented at [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Example.ogg). It downloads the unchanged original into temporary private test storage; no copy is included in this repository. The local FLAC fixture and its cover were generated by this project.

Screenshots/traces appear under test-results and are untracked. Audio validation establishes that Chromium decoded the file, reported positive duration, advanced playback time and had no HTMLMediaElement error; it does not verify physical speaker output, bit-perfect reproduction, gapless playback, OS background audio or mobile hardware behavior.

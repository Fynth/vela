# Browser regression tests

Fresh headless Chromium instances exercise the real Rust server, isolated SQLite/storage and built Dioxus WASM. No signed-in browser profile is used. `server.sh` owns and removes its own mktemp directory, never the development library.

```bash
cargo build --locked -p vela-server
scripts/build-web.sh
npm ci --prefix tests/browser
(cd tests/browser && npx playwright install chromium && npx playwright test)
```

Use `VELA_LIVE_IMPORT_TEST=1` to include the external direct-download import test; ordinary tests are deterministic and offline after dependency installation. The live test uses **Example.ogg by JesseW**, licensed [CC BY-SA3.0](https://creativecommons.org/licenses/by-sa/3.0/) and documented at [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Example.ogg). It downloads the unchanged original into temporary private test storage; no copy is included in this repository. The local FLAC fixture and its cover were generated by this project.

Screenshots/traces appear under test-results and are untracked. Audio validation establishes that Chromium decoded the file, reported positive duration, advanced playback time and had no HTMLMediaElement error; it does not verify physical speaker output, bit-perfect reproduction, gapless playback, OS background audio or mobile hardware behavior.

The suite also verifies private album/artist browsing/playback, stale collection responses, revisioned catalog edits with two real authenticated browser sessions, original playback after edits, draft-preserving conflicts, explicit reload, mobile dialog layout and cancellation before an account change. The configured-folder scenario uses real nested FLAC/MP3 files, scans through Settings, verifies dedup preserves edited tags, plays newly scanned audio, rescans, removes the source without deleting music, and checks a mobile layout. A full run has twenty scenarios; the live network import is opt-in (nineteen deterministic scenarios otherwise). Filter scenarios cover combined private filters/favorites/sorting, invalid drafts/reset/mobile layout, out-of-order filters, stale private suggestions after an account change, and real50+2 pagination while draft fields differ. That last scenario uploads52 distinct generated PCM WAV files through the production endpoint in isolated storage; it does not mock catalog responses. Scenarios reuse only earlier authenticated sessions belonging to this suite, held in memory, to keep the production login limiter unchanged.

Jobs scenarios inspect the real licensed import when enabled, run52 actual passes over the private FLAC/MP3 folder, use Scan again through the UI and verify preserved50+2 history pages, stable older-page refresh and real navigation. At320px five primary navigation controls remain visible; More exposes the remaining authorized destinations. Delayed responses use route.fetch() against the real API before holding/releasing them; only the deliberate HTTP503 outage is injected. Tests verify filter races, visible stale-data recovery, account-change isolation and absence of legacy import polling on Jobs. The unit/TCP suites separately verify deterministic queued import cancel/retry and scan cancellation/action authorization without relaxing public egress. No job history response or database row is fabricated by browser tests.

Experience scenarios16–19 exercise real Home cold-start/content, all four local search kinds,300ms debounce/Enter, actual AbortController cancellation, stale query/account replies, old play-promise rejection after a real newer play, duplicate-aware Play next/Add last and cursor restoration. The45s WAV is generated PCM test material uploaded through the production API. Navigation/theme/queue/More changes retain the exact same HTMLMediaElement/source and playing state. Screenshots experience-home-{320,768,1440,1920}-{dark,light}.png cover eight responsive/theme combinations, with overflow checks and reduced-motion enabled. The More sheet is tested with keyboard focus containment, Escape and return focus. These are scoped Chromium checks, not complete G02/G03/G13 or native certification.

# Unsupported and unverified functionality

This is an early functional slice. The complete master roadmap is not delivered. Consult PROGRESS for executed checks; source/build recipes are not proof of platform runtime success.

- No native desktop/mobile packages or audio services; no Android/iOS hardware validation, offline music, device transfer, remote control, PWA cache, background audio or secure native credential storage.
- No federation, profiles/follows/activity feed/rooms, peer discovery, connected-server adapter, unified multi-server search or OpenSubsonic routes. Federation remains disabled; no private content is published.
- No scanner/read-only libraries, WebDAV/S3/ZIP/Archive.org/feed adapters, cloud playlist metadata adapters or arbitrary commercial-service downloading. Direct HTTP/S audio and browser batch uploads are the only implemented ingestion paths. Browser preview knows filename/MIME/size, not pre-downloaded embedded album tags/artwork/license information.
- No FFmpeg transcoding, quality presets, ReplayGain, verified gapless/crossfade, speed/sleep timer or exact session-position resume. Uploaded uncommon containers/codecs may not play in the browser. No full-frame decode verification; later corrupt frames may survive metadata validation.
- Persisted album/artist groups and dedicated screens use trimmed names with SQLite ASCII NOCASE and album-artist/year keys (ADR0004). Unknown years remain provisional separate groups; Unicode case folding, verified editions/recordings, multiple encodings, genres/composer catalog, metadata editing and advanced filters remain planned. Catalog pages50/max100 use UUID keyset cursors; new randomUUID additions may appear before a cursor. Album pages follow disc/track order but edits between pages can move tracks. Queue contains selected pages, not the whole catalog. Missing album tags remain available through Library rather than an invented album.
- Playlists are capped at1000 entries and200 per owner. Named viewer/editor grants and expiring metadata-only links exist, but no separate media sharing, invitations/acceptance, owner transfer, activity/revision feed or SSE updates. Owner collaborator list/revocation and member-leave controls exist; stream access remains owner-only. Queue/playlist order uses accessible move-up controls, not drag/drop.
- Exact BLAKE3 duplicates are handled; logical recording/master/live/remix duplicate grouping, acoustic fingerprints, enrichment/ambiguous review, smart playlists, recommendations, lyrics, history/statistics, user export/collections/podcasts/radio are not implemented.
- Imports restart from zero rather than resuming byte offsets. Processing cannot cancel once atomic publication starts; automatic retries are limited to transient failures. Pause is unsupported. Conservative pre-download quota checks can reject a duplicate at a completely full budget. Progress uses active-job polling, not SSE.
- Managed budget accounts referenced physical audio only; per-file limits bound staging/artwork, but global thumbnail/orphan accounting and reconciliation remain work. A hard crash between publication and DB commit can leave retained orphan content. No garbage collector deletes source files.
- Current database layout supports one application process and one local SQLite data directory. An OS lock enforces this. Network filesystems/cluster modes are unsupported. Fixed resource limits have not established safe user counts; benchmark scope is explicitly documented.
- Container runtime/build, ARM64, Safari/Firefox, OS system controls and actual mobile hardware must be validated separately; only checks in PROGRESS count. CI has been configured but is not remotely executed/published by this session.
- No independent security audit, backup encryption, encrypted local browser catalog or public production deployment. No software updates performed on external servers.

- Dependency policy checks pass with the single documented unmaintained compile-time `paste` advisory exception. Generated license notices include packaged texts and pinned upstream texts for most crates;12 packages currently have metadata-only notices. External redistribution needs those notice gaps reviewed. No release was externally published.

# DR-06. Поднимите музыку в первый экран телефона

**Статус:** PROPOSED. **Приоритет:** P1. **Размер:** средний. **Пререквизиты:** нет. Один коммит: mobile listening composition <=760px; desktop не перестраивать.

## Цель

На320×700 первый трек с действиями полностью виден до мини-плеера; на390×844 пользователь видит больше коллекции и быстрее достигает работающей Wave. Плеер и пять пунктов навигации сохраняют доступные цели и единственное место в shell. Основание: DV-03 и S11/S12; L first row478..593 при safe viewport до510.

## Критерии приёмки

- На320×700 при100%scale, default filters, двух fixture tracks, без notices: first track top<=390px и нижняя граница обоих рядов<=510px. От baseline478px это минимум88px полезной высоты.
- На390×844 в той же сцене first track top<=350px; два полных113px row помещаются до654px. Активные filters/длинные названия могут увеличить высоту: действие остаётся доступным через main-scroll.
- Ноль горизонтального overflow на320/360/390/760/761/768; ширина document не больше viewport+1px. Actions не заходят на time/track и не обрезаются.
- Транспорт120, nav70, Play/Next/Queue44px, seek44px. Nav состоит из5 equal destinations, min rect44×44; без десятка desktop links.
- Header таблицы36±1px без пустой второй строки. В idle title читается целиком на320 при коротком словаре; current long title имеет штатный ellipsis.
- Empty editorial-card на390 с согласованным EN fallback занимает<=240px, высота растёт с текстом при150% app scale. CTA44px полностью внутри.
- Safe-bottom34px добавляет34 ровно один раз; test safe-top24,left/right16 не обрезает controls. Реальные device safe-area отдельно от эмуляции.
- Последний focusable track/menu action прокручивается выше полос с8px запасом; клавиатура не сбрасывает audio/source/queue.

Снимки должны включать last row после scroll-to-end, не только первый экран. Измерение safe-area через существующие --vela-safe-* overrides пометьте SIMULATED, без утверждения о реальном телефоне. Снимок320 с player на510 baseline не доказывает доступность содержимого ниже fold.

## Границы

Не меняйте desktop composition, auth/request generations, queue model/EOF/Next, media element и browser_player.rs. Feedback stack владеет DR-05, glass/underlap DR-02, анимации DR-03. Никаких новых assets/allowlist paths, manifests/migrations. media_assets/target/frozen runtime не трогать. Без публикации.

## Риски

Если оставить last empty header span, новая высота будет неверна. Активные filters и увеличенный текст требуют reflow, а не жёсткого viewport-fit. CSS zoom не меняет breakpoint viewport, поэтому проверяйте фактическую доступную ширину и existing scale contract. Не выдавайте эмуляцию safe-area за hardware validation.
